# 林边小屋 · 从木屋到石街镇

在原 Godot 工程打开 **`res://world/overland_demo/Overland.tscn`**，按 **F6（运行当前场景）**。也可以在工程根目录运行 `godot --path . --scene res://world/overland_demo/Overland.tscn`。不改 F5 主入口，不读写游戏存档或改键配置，建筑和魔物仍可在原试产场景中独立预览。

## 怎么走

- **WASD / 方向键**按屏幕方向移动，**Shift** 按住跑（项目默认手柄左摇杆／LB 同样映射到 Walker）。**滚轮**缩放，**V** 切换原生 **480×270 / 320×180**。加 `-- --320` 可按小档启动。
- **拱门木屋 → 井边村 → 林间兽径 → 石街镇**。出生后沿土路向画面右侧走，跟着琥珀色路牌。村里从井和菜地之间穿过，到谷仓外沿车辙入林。林路边依次有三处浅色砾石空地，靠近可看史莱姆回弹、哥布林挥棒和狼低伏前扑；三只在各自空地内循环待机、走动和演示，不追玩家、无伤害。出林后土路接入石铺主街，经镇屋、横巷到有条纹雨棚的面包铺；再往前到终点路牌。可原路走回，不用切换菜单或重生。
- 小屋与两处聚落均是可接近的外景。门台可走上去，门不开放；这不是主地图的室内、库存或战斗 Demo。

## 尺度与实现

1 Godot 单位 = 1 m；围栏内 **156×63 m**，从信使出生点到东侧终点的道路中心线 **150.25 m**（不计门台、观察点和横巷支线）。实际无停留跑完全程约 **38 秒**。原信使 Walker 模型、步态、碰撞和项目默认动作直接复用；镜头沿用 **30° 偏航、36° 俯角**、13.4 m 默认正交档、六档缩放、平面对齐像素及最近邻整倍显示。

`overland_map.gd` 生成一层共用地板／围栏碰撞、道路接缝和林地；`integrated_site.gd` 使用 `VillageLane.tscn`、`TownCorner.tscn` 的地块与门前路标，用原试产的路面和摆件生成器，去掉各自预览专用的地板、四周边界、相机和灯光。木屋只用原 `Cottage.tscn` 的外景。两处街区与三个魔物全部从起点驻留在同一个 `World3D`，同一信使控制到终点。地表和植被按条带批处理供视锥剔除，**没有分块读盘、异步流送、卸载、后台推演或跨块碰撞就绪测试**。

## Windows 实测

环境：Godot **4.7.2**，GL Compatibility / OpenGL 3.3，NVIDIA GeForce RTX 4090。以实际窗口分别直启 480 档和 `--320` 档；验证脚本 **无头 87/87、真实窗口 130/130**。用输入事件/动作驱动原 Walker（不是逐点设坐标，也不是手按实体键盘）：走过两处街区和全部林路观察点，进出城镇横巷，登上小屋和六座建筑的门台再回道路；闭门及东侧可见围栏会挡住，回程仍是同一角色和物理世界。

在玩家能够步行抵达的观察点，取两档分辨率的真实渲染，测量待机、走动和招牌关键帧。默认镜头下三只的待机剪影分别为（史莱姆／哥布林／狼）：

| 原生视口 | 剪影宽×高 |
| --- | --- |
| 480×270 | 27×20 / 28×28 / 46×27 px |
| 320×180 | 18×14 / 18×18 / 30×19 px |

六组招牌帧相较隐藏模型的同机位背景，均有 **93% 或以上**的剪影像素在至少一个 sRGB 通道相差 ≥ 0.12；动作改变剪影，各自名签在框内。这是白天、指定站位和关键帧的可读性抽样，并非所有角度、光照或连续动作的人工观感验收。远端工具不回显 PNG。

**性能（一次实时单向沿中心线路跑）**：960×540 实际窗口，内部 480×270、VSync 关闭、无限帧率，无固定时间步长或截图读回。**59,009 帧 / 37.61 秒，平均约 1,569 FPS**；主循环帧间隔 **P50 0.58 / P95 1.01 / P99 1.30 / 最大 7.29 ms**。Godot 子视口可见绘制调用最少 / 中位 / 最多 **153 / 193 / 869**。已预载 PackedScene 的实例化和加入场景树约 **175 ms**（不含冷启/导入/首帧）。数据不是 GPU 单独耗时，也不是低配机器或流式边界卡顿承诺。

```text
godot --path . --headless --fixed-fps 60 --script res://world/overland_demo/verify_overland.gd
godot --path . --disable-vsync --fixed-fps 60 --script res://world/overland_demo/verify_overland.gd -- --capture
godot --path . --script res://world/overland_demo/verify_overland.gd -- --perf
```
