# 农场魔物模型 · 蜘蛛、蜂、小恶魔

这三个 `.tscn` 是可单独实例化的**美术资产**，不是农场场景。按现有魔物的低多边形轮廓、顶点颜料与低分辨率正交视口制作，腿、甲壳、翅膜、角和火种都有正反面与体积。模型没有 AI、碰撞、投射物、伤害或场景注册。

## 接入

`res://art/farm_creatures/{Spider,Bee,Imp}.tscn`。每个根均为 `Node3D`；**+Z 是正面，Y=0 是地面**。蜂的飞行净空已画进模型。给宿主转向、移位即可，不要抬高蜂，也不要把视觉子树 `Rig` 的冲出位移再叠给宿主。

```gdscript
var model := preload("res://art/farm_creatures/Bee.tscn").instantiate() as Node3D
model.set("variant_index", 1)  # 0..2，可在入树前设置，或在播放中切换
add_child(model)
var player := model.get_node("AnimationPlayer") as AnimationPlayer
player.play(&"attack")
```

`AnimationPlayer` 是**直接子节点**。`idle` 自动播放并循环，`move` 原地循环，`attack` 单次，收招后由宿主切回 `idle` / `move`。变体共用同一套动作与节奏，换外观不重启时间轴、不改其他实例。下表时间是 `speed_scale = 1` 时从攻击片段开头起算的**视觉接触拍**，不是模型发出的命中事件。

| 场景 | `idle` / `move` / `attack`（秒） | 预兆 → 打击 |
|---|---|---|
| `Spider` | 2.40 / 0.72 / 1.02 | 后收重心，前两对腿扬起、双螯外张；**0.53 s** 低扑合螯。 |
| `Bee` | 0.80 / 0.48 / 0.84 | 上提悬停，双翼竖成 V、腹部开始下卷；**0.43 s** 收翼朝前冲，腹针从身下送出。 |
| `Imp` | 1.80 / 0.68 / 1.14 | 转肩抬掌，掌中火种变大、张翼短停；**0.62 s** 翻肩推掌，收翼回架。火舌附着在手上，不脱离模型。 |

## 外观索引与摆位尺寸

以下为 `idle` 第 0 秒逐顶点测量的**宽 × 深 × 离地最高点**（米），不等于碰撞体或攻击距离。尺寸以原点水平位置为中心近似摆位；实际几何不前后对称。

| `variant_index` | 蜘蛛 | 蜂 | 小恶魔 |
|---|---|---|---|
| `0` 基础 | **果园蛛**：棕甲、赭金双折纹；2.09 × 1.55 × 0.84 | **条纹蜂**：蜜金环带、浅青翅；1.51 × 1.38 × 1.40 | **灰烬小恶魔**：砖红皮膜、后掠角、橙火掌；1.55 × 1.04 × 1.47 |
| `1` | **月纹蛛**：紫灰甲、浅色侧缘、青眼；2.09 × 1.55 × 0.84 | **采粉蜂**：浅蜜绒领、双腿鼓起的花粉篮；1.51 × 1.38 × 1.40 | **磷火小恶魔**：蓝灰皮肤、内勾角、浅色斜肩带与冷火；1.55 × 1.04 × 1.43 |
| `2` | **赤棘蛛**：锈红腹甲带三对后斜棘；2.09 × 1.55 × 0.89 | **锈针蜂**：铜红条纹、更长的尖翅与腹针；1.68 × 1.47 × 1.42 | **炭袋小恶魔**：前翘角、分尾绿披肩和腰囊；1.55 × 1.04 × 1.47 |

蜂的最低可见部位距地约 0.52–0.58 m；蛛足与小恶魔蹄端贴地。基础移动分别是八足交错爬行、前倾振翅和摆臂换步。

## 双档实测与看图方式

[480×270 原生取样](proofs/480.png) · [320×180 原生取样](proofs/320.png)。每张从上到下是蜘蛛、蜂、小恶魔，每种占三行（0 / 1 / 2）；**左五格为近观察档，右五格为默认地图远景档**。每组从左到右是待机、移动中段、攻击预兆、接触、转身后的背面。格子是原纹素裁剪，没有放大模型冒充默认远景效果。

Godot 4.7.2 / OpenGL Compatibility 真窗口，以 F5 的 30° 偏航、36° 俯视、13.4 m 默认视幅和 6.2 m 近视幅，以主场景日光参数做独立模型测试，不加载、更改主地图。在默认视幅，九款模型的预兆与接触帧，480 / 320 档最少分别有 **371 / 163** 个可见像素改变；同种变体待机任两款最少 **87 / 41** 像素不同。320 档先认蛛的横向长腿、蜂的离地合翼、小恶魔的头角与掌火；花粉、袋扣和腹甲纹适合拉近看。这些是资产检查，不代表农场 AI、实际命中或地图内遮挡已验证。

从项目根复测（`godot` 替换为本机 Godot 4.7 可执行文件）：

```text
godot --windowed --resolution 480x270 --path . --script art/farm_creatures/source/check_models.gd
```

可加 `-- --proofs=<现有空目录>` 保存两张原生取样表；检查失败不输出。模型和动画均已烘入 `.tscn`，运行时仅依赖本目录的 `look.gd`；不需要现场建模。维护者修改 `source/` 的原型与姿势后，可运行 `godot --headless --path . --script art/farm_creatures/source/bake.gd -- --replace` 重烘这三个场景（未带 `--replace` 不覆盖已有场景）。作者工具复用原项目的 `art/monster_trial/source/brush.gd` 与 `rig.gd`，不修改它们。
