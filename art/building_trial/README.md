# 建筑素材试产 · 村路 / 城镇街角

## 打开与运行

在原工程的 Godot 4.7.2 中打开 `res://art/building_trial/BuildingPreview.tscn`，按 **F6（运行当前场景）**。不改 F5 主场景、不加载游戏存档。想在 3D 编辑器里看布置或改地块，直接打开 `VillageLane.tscn` 或 `TownCorner.tscn`，在 `Lots` 下选中实例编辑 Inspector；`BuildingLot.tscn` 是可重复放置的外壳模板。

- **1 / 2**：村路 / 城镇街角。**WASD / 方向键**走路，**Shift** 跑；角色是原工程信使及其移动/碰撞。
- **V**：480×270 / 320×180。**C**：建筑统一灰泥材质，保留体块、门窗、屋顶及雨棚几何。**L**：白天 / 薄暮。
- **F**：在定机位和跟随间切换。滚轮沿用游戏六档正交缩放，近档自动跟随。**R**：回到本图尺标出生点。

命令行（在仓库根执行，`godot` 可换为本机 Godot 控制台程序路径）：

```text
godot --path . --scene res://art/building_trial/BuildingPreview.tscn
godot --path . --scene res://art/building_trial/BuildingPreview.tscn -- --town --320
```

## 放置、复用和锁定

- **尺度**：Godot 1 单位为 1 m，Y 向上。原点是外壳体块中心的地表（Y=0），本地 +Z 是临街立面。地块宽、深按立面坐标输入，四侧含檐/窗沿余量；门台、铺面雨棚及招牌的前伸另留退界。不要靠缩放或任意旋转楼体迁就地块。`Street Face` 用 90° 档把立面转向临路一侧。信使的碰撞为半径 0.31 m、高 1.68 m。
- **尺寸与接地**：四类各有标准/紧凑体块，均是独立的固定宽、深、檐高；屋面按当前跨度生成。普通门净面 0.96–1.03 m；仓门较宽。试产门台高 0.13–0.32 m；外观有石踏步分缝，实际碰撞用连续斜坡接落地面，坡度小于约 21°。外壳、地面和主要道具为第 1 层静态碰撞；不使用随机凹凸瓦片作碰撞。
- **可重复**：`Lot Id` 是地块身份，`Appearance Seed` 是独立外观输入。`lot_rules.gd` 用版本化哈希按通道取体型、屋面、色板、烟囱、侧棚状态、门位及百叶；不读全局随机状态或时钟。运行时重建同一配置，不重抽。试产不接建筑存档。
- **可覆盖**：在 `Appearance overrides` 里将 `Seeded` 换为指定项。已锁的合法项不随种子变；坡台高、临街方向不参与随机。放不下标准体量会退到紧凑且报 Inspector 警告；紧凑也放不下则不生成。错跨度/错用途的屋顶、侵占陈列窗的门位、没有侧院空间的侧棚同样拒绝。示例：`FlaxFarm` 锁卷檐和左烟囱；`OrchardFarm` 由地块筛到紧凑体型，锁四坡屋顶；`AlleyLoft` 锁切角屋顶并朝 +X。
- **挂点及通路**：生成时每栋提供本地 `Generated/Anchors/DoorAnchor`（门槛）、`Landing`（可站立的台面）、`Approach`（坡脚外侧）、`Lamp`；铺面另有 `Sign`。这些挂点随门位和朝向移动。两个地景下 `Links/同名地块` 标记对应的路缘/路心连线，方向不合法则不画虚假的引路线。手动移动地块或路标后，通过地景 Inspector 的 **Refresh dressing and approach links** 刷新。
- **源码分工**：`building_lot.gd` 组装墙、石基、门台、各类立面与碰撞；`roof_profiles.gd` 共用瓦行/收边/脊盖；`joinery.gd` 共用门窗框与挂灯；`street_props.gd` 共用石、木和装货小件；`mesh_batch.gd` 与 `trial_pigment.gdshader` 批量绘制。`trial_site.gd` 摆置地面/路网/道具。`.tscn` 保存布置、参数与身份，生成网格不塞回 `.tscn`。

闭合的门只表示入口。没有室内、黑场、寻路、商店功能、存档或完整城市；预览也未移植主场景的遮挡描边。

## 截图和验收记录

`review/` 的 PNG 是 Windows 上 Godot 4.7.2 的 GL Compatibility（OpenGL 3.3，RTX 4090）**真实 SubViewport** 输出，不是窗体截取或事后缩图。与实际室外相机一致：偏航 **30°**、俯角 **36°**、默认正交尺寸 **13.4 m**，按相机平面对齐像素，最近邻整倍显示，无 3D MSAA。对照组保持同一机位；近照是游戏 **8.95 m** 档。

- `village_day_480.png` / `town_day_480.png`：白天总览；同名 `clay_480` 对比屋顶、门、雨棚和招牌不依赖色板的形状；`dusk_480` 对照薄暮，窗和灯具保持暖色。
- `village_day_320.png` / `town_day_320.png`：真实 320×180 复核，不是从 480×270 缩小。
- `village_stoop_480.png` / `town_shop_480.png`：高门台和铺面入口近照。

实测：三个场景入口均在窗口中启动；无头检查 **186/186**、窗口检查 **288/288**、窗口含 10 张写图检查 **298/298**。同一种子/输入重建的网格顶点与颜色一致，非法锁定走约束回退。原 `Walker` 从两段主路/横巷实际走通 **6/6** 座门台并返回道路，向门内继续走会被闭合外壳挡住。两档分辨率中六栋外壳的投影在框内；**52/52** 个门面、站位、招牌、道路中心点通过渲染深度可见性探针。探针确认抽样点未遮、图像非空白，**不等同于全域无遮挡或人工美术评审**；远端工具不回显 PNG。建议在 Godot 里用 C 比较轮廓、再走巷口看移动时遮挡。
