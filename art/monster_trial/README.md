# 林间图鉴 01 · 魔物试产

用《林边小屋》的斜俯视像素镜头试三种经典幻想轮廓：**贴地圆团、尖耳持棒、长身四足**。这是一组表现资产，不是遭遇或战斗原型。

## 运行与预览

在现有 Godot 工程打开 **`art/monster_trial/MonsterTrial.tscn`**，按 **F6**。也可在工程根目录运行 `godot --path . res://art/monster_trial/MonsterTrial.tscn`（Windows 上用实际的 Godot 4.7.2 可执行文件）。不用改主场景；展示不会加载小屋、建筑试产或玩家存档。默认循环展示待机 → 巡步 → 招牌动作；招牌动作错峰播放，便于看清每只的发力。

- **1 / 2 / 3**：固定循环待机／移动／招牌演示；**A** 恢复轮播，**空格**暂停或继续。
- **Z**：远近切换（室外默认正交尺寸 **13.4 m**／最近档 **6.2 m**）；**R**：**480×270**／**320×180**（也可加 `-- --320` 启动到小档）。窗口保持最近邻整数放大。
- **L**：白天／薄暮；**V**：纯剪影，移除魔物的材质色但保留外形和场地。

以下 PNG 均来自 Windows 上实际运行的 Godot 视口，不是建模软件预览或手绘替代图。可在资源管理器直接打开 `previews/`：

1. [01-field-480.png](previews/01-field-480.png) — 默认远景，白天，原生 **480×270**。
2. [02-dusk-silhouette-320.png](previews/02-dusk-silhouette-320.png) — 上方为 **320×180** 原生薄暮画面，下方为同机位、同姿势的纯剪影。
3. [03-action-poses.png](previews/03-action-poses.png) — 从 480×270 最近档取四条等宽原像素截图，自上向下为**待机、步态、蓄势、出招**；每列的关键时刻独立取样。全速动作请在展示里按 **2 / 3** 看。

## 可复用资产

| 资产 | 轮廓与材质 | 动画库（秒） |
| --- | --- | --- |
| [`Slime.tscn`](Slime.tscn) | 约 1.4 m 宽、0.8 m 高。偏心的青绿胶丘、展开裙边、深色双眼和不透明釉光。压扁时下沿保持贴地，拉长起跳，落地后有二次回弹。 | `idle` 2.40、`move` 0.76、`rebound` 1.56 |
| [`Goblin.tscn`](Goblin.tscn) | 约 1.6 m 高。尖耳、钩鼻和前探的弓背，赭布短衣、砖红领巾、不对称木棒。先撤肩亮棒，再探步横扫，空手反摆，最后收势。 | `idle` 2.80、`move` 0.88、`feint` 1.52 |
| [`Wolf.tscn`](Wolf.tscn) | 约 2.8 m 长、1.3 m 耳高。灰褐鞍背、浅胸鬃、长吻、粗直低垂的尾巴。对角小跑，先降胸蓄力，再后腿蹬伸、前爪接地。 | `idle` 2.80、`move` 0.66、`pounce` 1.76 |

- 三个 `.tscn` 可单独实例化，**不依赖展示、生成脚本、共用主题、外部贴图或插件**。1 Godot 单位 = 1 m，统一 **+Y 向上、+Z 正面**（与信使一致），根原点在脚下，不需导入缩放。放进宿主场景时移动的是实例根，不是 `Rig`。显示用 `MeshInstance3D` 不设玩法碰撞层。
- 每个实例的 `AnimationPlayer` 默认循环 `idle`。`play("move")` 循环；`rebound` / `feint` / `pounce` 单次结束，可在 `animation_finished` 后切回 `idle`。`RESET` 为中立姿势。所有轨道只改 `Rig` 及下属枢轴；移动不改实例根，狼的短前扑亦在 `Rig` 内向前再收回。宿主自己决定位移、朝向、节奏与安全占位。
- 可定位节点：`Look`（视线，位于各头部或胶丘内），哥布林 `Rig/Hips/Spine/ClubShoulder/Elbow/PropSocket`（木棒挂点），人形／四足的 `Sole`（脚底检查点）。造型都为命名原生节点，关节可编辑；动画关键帧在库中。颜色为场景内 `StandardMaterial3D` 与模型的顶点色，改同一资源的单个实例前应复制资源。
- `source/*_model.gd` 是轮廓截面、调色、摆位和动作源；`source/brush.gd` 是三角面笔刷；`source/rig.gd` 离线把姿势和两段腿求解烘成原生动画。运行 `godot --headless --path . --script res://art/monster_trial/source/bake_monsters.gd` 可重建三份场景，若已存在则拒绝写入；确认要舍弃场景中的直接手改时才加 `-- --replace`。预览场地由 `study_set.gd` 构建，图签沿用工程羊皮纸主题。这批模型、动画和场地为本试产原生制作，没有外采素材或新增署名／授权依赖。

## 实测和边界

在执行设备 **Windows / Godot 4.7.2 / OpenGL 3.3 Compatibility / RTX 4090** 运行。镜头比照室外 **30° 偏航、36° 俯角**、视平面像素对齐和无 MSAA；照明用主游戏 14:00 / 18:40 的环境光与日月光参数，场地则是独立的林间小径。没有在主地图加入怪物，也未验主地图树冠遮挡、战斗距离或实际取景中心。

- 无头 **52 项通过**：检查实际 PackedScene、每只三个动画及关节轨道、实例独立、单次动画完成信号、根位置不受动画影响。史莱姆蓄力高度比例最低采样约 **0.38**、回弹抬高 **0.37 m**；哥布林蓄势到挥出棒梢移动 **1.74 m**；狼身体中心由低伏 **0.48 m** 抬到 **0.91 m**，前探 **0.55 m**。移动脚底标记最低约 **+9 mm / −1 mm**（哥布林／狼）。
- 有窗口 **217 项通过**（含无头那组数据检查）：经窗口输入事件切换各演示档；对 480×270 白天、320×180 薄暮和近档动作抽取实际帧，比较逐个魔物的遮罩；检查小图签有实透底缺口、文字未挤出。另从场景入口分别以 480×270 与 `--320` 启动，各运行 600 帧（60 fps 固定步长，覆盖一轮自动播放），没有 Godot 错误或警告。
- 同一远镜待机帧，三只轮廓的宽×高为 **27×20 / 26×27 / 49×26 px**（480）与 **18×14 / 18×18 / 32×18 px**（320），均未互遮；近机巡步九个方位及关键帧样本没有裁边。仅在执行器中读取像素和形状数据，当前远程工具不能回传视觉预览；上面的 PNG 留在 Windows 工程中供肉眼复核。

复跑：`godot --headless --path . --script res://art/monster_trial/verify_trial.gd`。去掉 `--headless` 验实际窗口；加 `-- --capture` 可重写本目录的三份预览。输入检查使用 Godot 键盘事件，不是实体键盘／手柄实按。

本轮每只仅一套配色，用刚性枢轴而非可重定向的 `Skeleton3D`，没有足底贴坡或转身免滑保证。没有 AI、碰撞、命中、数值、掉落、存档或主场景接线；不依赖建筑试产。
