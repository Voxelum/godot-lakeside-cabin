# F5 · 短对话测试

在主地图靠近榛树园丁（榛树附近）或井边陶工，按 F 或当前「使用」绑定。对话默认聚焦「继续」；Enter／手柄 A 确认，方向键或十字键在按钮间移动，鼠标可直接点击，Esc／手柄 B 离开。每人两句，无任务、分支、AI 或存档状态。

## 目标优先级与立绘

活动世界中 1.65 米内最近的可见绑定 NPC 优先于拾取；对话回调返回 `true` 则本次使用立即结束。不合条件时由原有拾取流程继续。黑场、切换地点及其他模态界面不开放对话。对话开启／结束由独立脚本通知 FieldSession 切换输入锁，不另监听 F。

`FieldDialogue.tscn` 中的说话实体绑定配置实体路径、姓名、固定文本及可选 `Texture2D`。对话面板只读取选中的绑定；两张项目自制 SVG 是暂用立绘，未绑定图片则显示通用剪影。更换图片不触碰 3D 角色。底部羊皮纸长框只放对白和原有按钮，不再内嵌小头像。当前说话人的透明大立绘按原比例放在屏幕左下，主体向纸面上方延伸，不加底板；独立姓名签压在纸面左端上沿，不遮正文或按钮。面板、姓名签与按钮分别沿用共享大页、`PaperTag` 和按钮焦点样式；不加全屏遮罩。

对话排版取共享的 [UI 逻辑框与安全区](ui-layout.md)，不受世界 480／320 缓冲影响。底纸占 16:9 客户区的 72.5% 宽；对白与行囊正文使用同一个 `BODY` 字号。独立立绘与姓名签各有净空。

## 实测

Windows / Godot 4.7.2，窗口渲染运行 `godot --path . --script res://tests/dialogue_checks.gd`。加载 F5 原场景，在 960×540（480×270 像素缓冲）及 320×180（320×180 像素缓冲）验证真实输入派发（测试注入键盘、手柄和鼠标事件）、模态锁与恢复、四边透出世界和立绘透明边角的像素读回、立绘确实绘于纸面上方、姓名签与正文／按钮不重叠、两位说话人姓名与立绘同步切换，以及缺图回退且原 3D 模型未改变。重叠夹具有可取物时一次 F 只开对话，离开说话范围后同一操作仍可拾取。夹具只存在于测试进程中，不写存档。
