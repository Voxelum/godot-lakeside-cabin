# 湖畔小屋 · 八种魔物的外观名册与旧路线记录

**当前 F5：** 这 24 种外观均已迁入[铁匠铺东侧的魔物农场](monster-farm.md)，和蜘蛛、蜂、小恶魔共 33 只。下面保留的是上一版路肩展示的位置和当时的验收，不再是当前试玩路线；各独立艺术资源仍可复用。

从 [Main.tscn](../Main.tscn) 按 **F5**，沿原 Clearing 的石路、井边村、林间兽径走向石街镇。[MonsterField.tscn](../world/monster_variants/MonsterField.tscn) 只增加八个草肩观察区：**原有六种、全新两种，每种三款，共 24 款**。六只原型保留在原位，新增 18 只；没有把展示位放在车道、建筑门口或街后市集。武器仅为空间中的道具，不增加攻击、追踪、伤害或掉落；原咬根花的既有行为未改。

## 迁移前的 F5 站位（历史截图索引）

背向小屋，沿脚下米白石路朝初始画面左下走，石板渐疏后沿车辙去水井。到了下列地标才短暂离开车道，原路退回再继续；左右以**朝石街镇前进**为准，括号是可站的 Clearing 局部 XZ，可用作编辑器坐标参考。

1. **巨鼠（11.65, 26.56）**：走到井旁，绕过井边灯柱靠水井的一侧，站井与路灯间净地，三只在井外草边。不用钻进菜地。
2. **史莱姆（17.10, 36.57）**：经过铁匠铺路口后，车道斜转向林间的第一块草肩，在一道刻痕木牌的来路侧停；琥珀伞胶在偏回铁匠铺的一端，不必走上门台。
3. **哥布林（10.73, 45.91）**：过新旧地形接缝，到两道刻痕木牌的草侧；尖耳和武器从草坡上露出来。
4. **兽人（14.55, 45.42）**：回到车道，再从同一段往**对侧**草肩走两步；三只沿浅坡错开站，不在道路上列队。
5. **咬根花（16.03, 50.77）**：下一个弯向兽径外肩探一步；看靠矮坡的三团花，留在侧肩，不用挤到叶片之间。
6. **狼（14.95, 57.83）**：过石坡路灯，在三道刻痕木牌前偏向林内的空地，草地上的低轮廓不是路障。
7. **骷髅（17.51, 60.29）**：回到车道，再往镇方向走一小段，靠狼的同一侧站看短坡；鸢盾、圆盾、长矛依次可辨。
8. **僵尸（17.70, 65.72）**：进镇前最后一段土路，向石坡草肩探几步看三个拖步轮廓；退回车道即可继续走进镇，不用穿过僵尸或绕到街后。

## 如何复用

把 [art/monster_variants](../art/monster_variants/) 中任一物种 `.tscn` 拖进有地面和灯光的 3D 关卡；脚底为原点，`+Z` 是角色朝向。Inspector 的 `Variant = Base / Variant I / Variant II` 对应表格；`Weapon` 只对哥布林、骷髅、兽人、僵尸有意义，默认 `Preset`，可选空手、棒、矛、宽刀、斧、槌、弯刃、月钩。脚本实例化时在入树前设置。`main_grip` 指向跟随前臂的 `Marker3D`，挂点局部 `+Y` 沿武器持握轴；哥布林和新增两种人形还保留另一手标记，骨架的盾位也独立。配置武器时不会额外生成碰撞或更改行为。

- 史莱姆、哥布林、狼、巨鼠和骷髅沿用各自原 3D 模型与关键帧；新配件是三维网格并随同一套关节。咬根花保留原下花托及铰接上颚，变体把棘、萼、囊分别接到植株或上颚。
- 兽人和僵尸是新建的闭合体块、面部与分节肢体，不是纸片或八向贴图。两种族用同一关节拓扑和腿部求解，各有同族共享的动画：兽人阔步、挺胸举臂，僵尸脚步不对称、抬臂前倾，与体态绑在一起；款式不会复制一套动作代码。
- 每物种一份体碰撞资源，基础与变体的碰撞尺寸不随服饰、盾或武器膨胀。现场新演员沿用 `field_body.gd` 的移动扫掠和转身查询；`roam_radius = 0` 时只在原地播姿势。F5 站位由 `MonsterField` 接地；独立放置时在关卡中给脚底设高度，需要游动时可用物理地面或注入 `set_ground_sampler`。咬根花不移根。
- `signature()`、`duration(clip)`、`set_display_pose(clip, 0…1)` 可供预览脚本使用；接管姿势前暂时关闭实例的物理处理，恢复处理即返回原时间表。动作接口不决定战斗或存档。独立资源不依赖 `Clearing` 或灯光预设。

## 本轮验证

Windows / Godot **4.7.2** / OpenGL Compatibility / RTX 4090。使用 F5 相同入口、真实 **480×270 / 320×180** 窗口及同尺寸 `Pixels`、默认 13.4 m 取景，未写入真实玩家存档和改键文件。

- [魔物回归](../tests/monster_variants_checks.gd)两档均 **212/212**（含落图）。覆盖八个侧肩的连续进出、95 m 原线到镇尾并回到原出生点、18 只新演员的真实物理形状和冲撞接触、定时待机／移动／招牌动作、实体与可见根随同移动。全程经实际 `Walker` 的相机相对输入；路径 0 帧离地，最大步长约 7.1 cm，未撞到新魔物；独立碰撞探测的最小中心差约 0.56–0.81 m。根生花只有张合无位移。
- 八站的日间动作照片中，24 个网格剪影在 **480 档至少 189 px**、**320 档至少 85 px**。以隐藏该个体的同机位背景比较，两个档位所有抽样均有至少 **77%** 剪影像素在一个 sRGB 通道相差 ≥ 0.085。这是可见性检查，不是连续光照、动画全程或美术目视验收；执行器不能回显远端 PNG。
- [原地图路线回归](../tests/clearing_route_checks.gd)两档均 **34/34**，包括镇巷、七处门台、原路线往返和 F5/F9；`--assets-only` 验了 **24/24** 独立实例的三维体积／碰撞／姿势，其中四种有手魔物另试了矛、斧、月钩替换。

复跑：`godot --path . --disable-vsync --fixed-fps 60 --script res://tests/monster_variants_checks.gd -- --sheet=user://monster-check-480.png`。小档在 `--` 后另加 `--320` 并给一个新的 `--sheet` 文件名；如只检查资产独立复用，启动时用 `--headless`，把 `--` 后的参数换成 `--assets-only`。
