# 林边小屋 V2 · 走进小屋

在 **Godot 4.7.2** 项目管理器中导入 `project.godot`，按 **F5** 运行。工程不需要 .NET、插件、联网或参考图原件。

## 先走一圈

1. 无存档时出生在低处的米色石路。**WASD / 方向键**按当前画面方向走，**Shift** 按住跑，**滚轮**缩放。普通模式不旋转；要核对机位可在 `Main.tscn` 根节点启用 `developer_camera`，或运行 `godot --path . -- --dev-camera`，再按 **Ctrl + 鼠标左键**拖动。**F** 近身使用或对话。 [近战默认键位](./combat-prototype.md)：左键攻击、右键按住防御、Ctrl 松手翻滚、R 拔／收已装备武器；换武器在角色面板操作。
2. 顺石路上小坡，灰赭色岩坎是边界，不用跳。正面走过**蓝绿色拱门**的浅色门槛，无需按交互键。圆从门边收拢，全黑后才换到室内。
3. 屋内镜头固定。可以走到桌椅和地毯边；从前墙两个门柱之间往外走即可返回。若一直按住一个方向过门，开幕后先松开再走，避免误折返。
4. 回到低处，沿草边向左侧橡树走。在室外按 **2**，看树冠右下缘透出的暖光。保持机位用 **B** 暂时屏蔽／恢复光束；需要换角度时在开发模式下拖动相机核对。按 **3** 看树荫前沿的几只晚萤。

| 室外按键 | 作用 |
|---|---|
| **1** | 14:00 白天。开场默认时刻。 |
| **2** | 16:45 林间斜光。自然可见时段 16:30–17:00，边界渐变。 |
| **3** | 18:40 薄暮。飞萤只在傍晚时间窗出现。 |
| **B** | 只屏蔽／恢复光束，不改机位、太阳、阴影或时间；在时段外不会强行开灯。默认开启。 |
| **H** | 显示／隐藏像素时钟。 |
| **P** | 暂停／继续已有的池畔时钟；选 1 / 2 / 3 会定住时刻，方便对比。运行时按住 T 可快进。 |

这是从原「池畔昼夜」继续制作的独立副本。池塘倒影、温室、拱门小屋、树林、真实投影和渲染器保留；本次没有增加任务、家具交互或新昼夜系统。

## 魔物园：从原地图走进去

背向小屋，沿米白石路、车辙走过井边村的水井。到铁匠铺门前的弯道，走**绿爪木牌指向的碎石岔路**，穿木门架即到园门水槽。中央步道安全；绿牌五栏是一层、铜牌六栏是二层。跨入栏内、面向怪物按左键；右键正面格挡。离栏即脱战，水槽边按使用可补满生命和重置。见[路线、三十三只怪与打法](monster-farm.md)。

## 旅途手册与桌面拾取

- 点击游戏右下角 **设置**，或按 **Esc / F2 / 手柄 Start** 打开旅途手册。可以**保存进度、读取存档、操控与改绑、返回游戏**。第一次保存后才可读取；在手册中覆盖原档或读取需再点一次确认，Esc / 返回可取消。F5/F9 仍是游戏内快捷方式，同一个槽位。
- 走近箱子，箱盖会渐开，但**不自动取物**；远离未取空的箱子会渐闭。沿屋内餐桌靠地毯的一侧站到面包和茶杯旁，物品旁的羊皮纸浮签列出可拿的东西。按 **F** 或默认手柄 A，每次取列表首项，物件从桌面飞入角色；面包板留在桌上。按 Tab 查看带图标的物品列表，选择不同物品可读说明。
- **池岸走法**：在温室临水面、岸灯旁的低草缘，朝石路上坡，不用找跳跃点；沿岸两个方向都可回到路上。池面和温室外墙仍不可穿过。
- 后续制作请先读 [AGENTS.md · 场景交互与界面原则](AGENTS.md)。

## 地基验收：不用任务或新地图

以下从无存档状态说明；已有档会自动恢复。要重复从零验收且不动自己的档，请用 [SYSTEMS.md §3.3 的隔离测试](./SYSTEMS.md#首轮验收记录)，不用删除玩家档。

- **A · 行囊和箱子**：在出生点按 **F** 一次（湖畔石 ×1），Tab 查看。走进小屋，靠近门边小箱时箱盖渐开，按 **F** 取出 ×3；出屋、再进，箱中仍空。角色不在转场或菜单中时按 **F5**，退出并重新运行，仍在保存的地点，行囊 ×4；也能用 **F9** 主动读回。进门不写盘。
- **B · 场景外推进**：在湖岸看右上角 `湖岸 · 库存 12 | t=0`。按 **F6** 显式提交测试段 `[0,1)`，湖岸变 11。沿石路上坡，无黑场穿过区界；坡上的木托盘展示样品，读数为 **1 / t=1**。走回湖岸再上坡，或读回推进后的档再按 F6，仍是 1。F6 重放相同区间，不是「下一天」。
- **改绑**：**F2 → 操控与改绑**，选动作的「键鼠」或「手柄」格，按新键或拨动对应轴；成功即保存，另一列不变。有重复会拒绝；**Esc** 取消，底部按钮恢复默认。手柄**临时**默认：左摇杆移动、LB 按住跑、X 攻击、A 使用、Back/Select 行囊、Start 设置。菜单可用方向十字键移焦点、A 确认、B 返回；不同手柄的标字可能不同。背包和设置会锁住角色与玩法输入；退出后先让方向、跑键回到中立。

## 编辑入口

- **`Main.tscn`、`scripts/pixel_window.gd`、`scripts/door_iris.gdshader`**：室外/室内各自有独立 World3D 和 SubViewport。圆心来自当侧 Camera3D 对 `DoorAnchor` 的投影，半径以内部像素计；半径到零并实际绘出全黑帧后才安置人和切世界。室内使用自己的 `Entry`、环境和相机。
- **`world/Interior.tscn`**：原生节点的剖面小屋，可在 3D 编辑器改木梁、地板、窗、家具、灯和碰撞。**`world/Clearing.tscn`** 是室外总场景。
- **`art/courier/Courier.tscn`**：原创银发林间信使。模型正向 +Z；左右 `Thigh → Calf → Boot` 各自有髋膝踝转轴，脚跟/脚尖有接地点标记。`Courier.gd` 用实际水平移动距离驱动双段腿 IK，停步时有呼吸和眨眼。
- **`scripts/orbit_camera.gd`**：六档正交尺寸 6.2–15，俯角 29–49°。平移在镜头平面上对齐内部像素；旋转时不改内部尺寸也不加模糊。长时遮住人时只描出被挡部分，不把整棵树或整栋屋子变透明。
- **`art/terrace/BanksideRise.tscn`**：沿用原石路和植物，烘焙出 0.92 m 的低台、连续土坡与石路碰撞、露岩和碎石。旧地景保留。选用 `source/bake_terrace.gd` 可重建默认编号副本。
- **`art/sunbreak/Sunbreak.tscn`**：树冠的 4 个缝隙标记可移动；`radii` 是截面半径，`density` 是浓度。实际太阳决定光轴，碰撞与场景深度限制光程；`starts` / `ends` / `feather_hours` 可调，不依赖体积雾。
- **`art/wildlife/ForestLife.tscn`**：两只雨燕、一只林兔、两小簇共五只晚萤。可改飞行折线、草边停靠点及萤群位置。

## 窗口、全屏与像素分辨率

- **内部渲染 ≠ 窗口大小。** F5 默认使用 **GL Compatibility / OpenGL 3.3，480×270** 的场景视口；用 `godot --path . -- --320` 或主场景的 `resolution_preset` 选 **320×180**。仅室内 3D 几何使用 4× MSAA，不改变内部像素尺寸。独立进程默认普通全屏。退出全屏后可拖边调大小，也可用窗口标题栏最大化；试读建议至少 **960×540**，两档均可缩至 **320×180** 验证布局。界面按实际客户区用 [共用逻辑框及字号](./ui-layout.md)，与世界缓冲尺寸无关。
- **全屏：** 游戏中打开右下角 **设置**（或 **Esc / F2 / 手柄 Start**），选 **切换全屏**；再次打开设置，选 **退出全屏**。恢复进入全屏前的窗口尺寸和位置，或恢复最大化状态。Esc/B 仍是返回键，不另占游戏快捷键。
- **编辑器嵌入运行：** 游戏画面受编辑器「游戏」面板大小限制，不是渲染分辨率限制。在 Godot 的运行选项关闭 **Embed Game on Play（嵌入运行）** 后重新 F5，或用 `godot --path .` 独立运行；嵌入时设置只显示「嵌入预览」，不尝试切换系统全屏。
- **画面适配：** 内部视口保持原尺寸，输出保持 16:9、最近邻，以能放下完整画面的最大倍数居中显示；只有窗口比例不符时才需要黑边。例如 2560×1440 全屏，480 档为约 5.33 倍，部分像素占 5 或 6 个屏幕像素，仍不混色但像素宽度不完全一致；320 档恰为 8 倍。追求像素完全等宽，可用匹配内部档位的整倍窗口尺寸（例如两档都适用的 960×540）。
- **复测：** `godot --path . --script res://tests/display_checks.gd`，或末尾加 `-- --320`。使用实际桌面窗口（不加 `--headless`）。覆盖任意尺寸窗口、最大化、全屏、退出恢复、角色面板和菜单输入。角色与对话同机位对照、字号和净空量测见 [`ui_layout_checks.gd` 与实拍](./ui-layout.md#ci010-实窗数据)。
