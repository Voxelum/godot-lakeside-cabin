# S11 · 即时近战原型

直接运行 `Main.tscn`（编辑器 F5），无需另开测试地图。

- **左键 / X**：收刀时是空手拳；出鞘时剑横挥、长枪向前突刺。先朝目标走一步决定面向，再出手。攻击期间有出手与收势，按住不会连发。
- **R / L3** 只拔出或收起已装备的主手武器。空主手按 R 不出武器；未出鞘的攻击仍是徒手。**Q / R3** 不再切换武器，改用角色面板里的行囊装备剑或长枪。装备后默认收起，收起时显示在身侧；未装备则不显示。长枪手位仅为原型，不锁副手，也没有双手装备规则。
- **右键 / RT** 按住防御，松手取消；面向来袭方向时只承受原伤害的 25%（向上取整）。**F8** 打一记 5 点正面测试伤害，可对比格挡失去 2 HP、未格挡失去 5 HP；成长只统计实际失去的生命。
- **Ctrl 松手 / RB** 翻滚，有短暂无敌段，走碰撞而非传送。开发模式保留 **Ctrl+左拖**：左键按下即取消待执行的 Ctrl 翻滚，不出手；未按左键的 Ctrl 松手才执行。
- **F / A** 使用或对话；可达的当前场景 NPC 成功开始对话时，消费本次使用，不拾取。对话、菜单和过门会停止玩法输入、取消进行中的战斗动作；对话仍接收自己的 GUI 输入。

**要打真正会还手的敌人：** 从井边村铁匠铺弯道沿绿爪路牌进[魔物农场](monster-farm.md)。一、二层共 11 种 × 3 个体；咬根花不再放在原路边。进入围栏才能交战，园内支持倒下、脱战归位和重试。石街镇长凳西侧的点灯人仍是此前的独立 40 HP 动作测试体，不会主动攻击，也不是农场敌人的目标。

## 实现与边界

`field_combat.gd` 管输入提出的动作状态、出手时点、扇区与距离、阻挡射线、单次命中和受击。拳／剑／枪的原型伤害为 5／9／11，半径为 1.10／1.63／2.20 m，挥剑覆盖更宽、长枪更窄。只取同一 `World3D` 中扇区内最近且未被阻挡的目标，HUD 显示实际伤害。伤害走 `ActorStats.take_damage`，动画不能扣血。`combat_motion.gd` 提供动作、时长与归一化身体姿态；`drive_combat(action, progress, direction, weapon, drawn)` 由 Isaac 骨骼、点灯人肩部枢轴和咬根花花瓣分别适配。不是每个模型都要有一套人形骨骼。

室内外玩家仍共用一个 `ActorStats`；主手装备与本次出鞘状态随当前游玩跨门，动作和相位不跨门。玩家 HP 和装备栏随存档持久化；出鞘状态、测试对象 HP、动作时点不写入，读档后武器收起。农场对手的血量／仇恨同样不落盘，F9 重置各栏；玩家在园内原脚点恰好与新生魔物重叠时，落在同栏的安全步道。用同一改绑界面保存战斗动作；旧版右键使用迁至 F，能与新动作兼容的旧改绑保留。

## 验证

Windows / Godot 4.7.2 / GL Compatibility，真实渲染窗口内用 Godot 输入事件驱动（非实体手柄操作）：`--script res://tests/combat_checks.gd` 默认 **480×270** 和加 `-- --320` 的 **320×180** 均为 0 失败，覆盖同屏装备／行囊／属性的键鼠和模拟手柄导航、穿卸、读档不重复发放、三种攻击、独立人形及非人形 HP 和动作、格挡减伤与成长、滚动免伤、Ctrl 镜头组合、改绑保存与生效、对话锁和跨场景角色状态。`dialogue_checks.gd` 在这两档通过，包含重叠时对话优先、Enter／手柄 A／鼠标。`play_checks.gd` 的真实过门、跨进程读档、桌面拾取和菜单两档均通过；`binding_checks.gd`、`device_checks.gd` 和 `growth_checks.gd` 也通过。
