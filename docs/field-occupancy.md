# F5 户外居民与魔物：实体占位

**位置更新：** 居民仍在原处；包括咬根花在内的魔物已集中到[可步行进入的魔物农场](monster-farm.md)。下文魔物的路肩坐标、展示时序和对应测量是迁移前的制作记录，不是当前遭遇规则。

从原工程 **F5 / `Main.tscn`** 进入，默认仍是 Isaac。WASD／方向键走、Shift 跑；留在车辙或石街上可绕开所有居民和魔物。想体验身体阻挡，就从路肩朝角色身体走或跑；碰到的是角色本身，不是提前触发的攻击范围。没有另建地图或改主角模型、室内布局、玩家胶囊和存档格式。

## 如何复用身体

[`FieldBody`](../art/field_cast/field_body.gd) 是一个 `CharacterBody3D`：配置 `body_shape`、`body_center`、必要时 `body_rotation_degrees`，或在入树前用 `use_capsule(radius,height)`。以脚下为原点，把模型挂为直接子节点；场景已有的第 1 层即 Walker 与场地碰撞契约。身体不包括道具、尾梢、指尖、叶尖或大帽沿；占位不是逐帧对着所有像素复制一份网格。`SolidBody` 是实际 `CollisionShape3D`，没有 `Area3D`、攻击、伤害或掉落路径。

- **人形**用竖胶囊。半径／总高（米）：另一位主角苇羽 `0.27 / 1.62`、岚 `0.31 / 1.77`，榛篱老人 `0.25 / 1.48`、井边陶工 `0.34 / 1.64`、面包跑堂 `0.215 / 1.27`、补网人 `0.30 / 1.65`、点灯人 `0.27 / 1.88`。另一位主角换人时移除旧身体，再生成对应的新身体。
- **魔物**：史莱姆使用半径 `0.49`、高 `0.53` 的矮圆柱；哥布林、骷髅兵、咬根花用竖胶囊，分别为 `0.27 / 1.46`、`0.28 / 1.57`、`0.32 / 1.03`；狼、巨鼠用沿躯干的横胶囊，分别为 `0.32 / 1.58`、`0.25 / 1.02`（不含尾巴）。原五只魔物展示用模型仍可作为无碰撞外观复用。
- **移动**：跑堂和三个旧林间魔物只走原有的小范围时序。在物理步扫掠身体后，模型随共同的根移动；跑堂以实际走过的距离推进步态，被玩家挡住时不能走穿或把玩家推走。狼在转身时先检查横向身体的新朝向。史莱姆的弹跳纵移、狼前扑的根位移从 `Rig` 动画交给实体根；内部缩放、弓身和肢体动作仍是表现层，不让视觉跳起而身体留在地上。流程不包含寻路、追逐、战斗或持久日程。

## 实跑结果

Windows / Godot 4.7.2 / Jolt / GL Compatibility。两档都使用真实渲染窗口和原 F5 入口，注入镜头相对输入，经 `Walker` 的物理移动。测试用隔离槽；没有改真实玩家档或键位。

- [户外占位](../tests/field_occupancy_checks.gd)：**480×270 / 320×180 各 125/125**。12 个实体均能分别挡住走和跑的 Walker；同测默认 Isaac、换角不留隐形占位、主路全程往返。跨 840 个物理帧抽验移动者的真实位移和碰撞射线，跑堂走完 `2.140 m` 原支线；在玩家挡路时停住，玩家让开后能继续。史莱姆相对地面根高从 `0.014 m` 到 `0.387 m` 再回落，模型根与实体根同步。单次白天路边视野取样的剪影，补网人／点灯人／咬根花在 480 档分别为 `23×33` / `16×41` / `26×25 px`，320 档分别为 `16×22` / `11×27` / `17×17 px`；不等于对白天全程、夜间或所有视角做了人工美术验收。
- [原地图连续通行](../tests/clearing_route_checks.gd)：两档均 **34/34**，实走出生点至镇尾约 `95 m` 再折返，经过三个观察肩、镇巷、七处门台，覆盖 F5/F9；坡面仍有每档 6 个短暂离地物理帧，未卡住。
- [现有门槛](../tests/interior_door_checks.gd)：两档均 **0 失败**，七处户外门槛和原小屋可进、可出，铁匠敞棚可原地出入。另以显式 Reed 夹具运行 [旧角色回归](../tests/character_trial_checks.gd) 完整路线，两档均 **95/95**，保留步态、招牌动作和 F5/F9 无外观字段检查，并验证村民有实体且无攻击区。
- [旧林间魔物与外立面取景](../tests/clearing_render_checks.gd) 两档 **0 失败**；[第二批素材检查](../art/content_batch/batch_review.gd) 两档 **102/102**，巨鼠／骷髅的独立模型依然无脚本、无碰撞，实体仅由 F5 宿主提供。

在工程根目录复跑（Windows 下可用实际 Godot 控制台程序路径）：

```text
godot --path . --disable-vsync --fixed-fps 60 --resolution 480x270 --script res://tests/field_occupancy_checks.gd
godot --path . --disable-vsync --fixed-fps 60 --resolution 320x180 --script res://tests/field_occupancy_checks.gd -- --320
```

把脚本换成 `clearing_route_checks.gd` 或 `interior_door_checks.gd` 可复跑对应回归。暂不覆盖从任何任意存档坐标强制重叠、更多分支地形摆位、或今后的战斗与交互判定。
