# 湖边小屋 RPG：设计 grounding

来源：[11 月 21 日设计对谈纪要](../note)。这份文档记录设计方向，不代表 Godot 工程已经实现。以下区分共识、倾向与未决事项。

## 已达成的共识

- **道具要让玩家舍得用。** 基础消耗品应容易补充，常见物品可有多种游戏内用途。参考魂系血瓶：核心补给使用独立、常驻且可升级的槽位，降低即时战斗中的选择成本。无伤本身就是玩家的奖励，不必强迫所有人用道具。
- **低魔架空，先做四系。** 火可直接施放或附魔，水与火可组合，雷可引燃，风偏扩散和加速、组合较弱。不做会直接改变地形的土、木系：既难让玩家直观使用，也难让世界模拟闭环。元素力只属于主角和极少数人，主角可驾驭全部四系。科技表面不发达，但可以用不同方式实现熟悉的功能；怪物先考虑史莱姆、哥布林等经典类型。
- **没有等级，以行为塑造属性。** 不发自由属性点；做什么就成长什么，例如承受伤害练体力、攻击练力量，长期不用则相应退化。讨论过用年龄代替等级，未采纳。
- **第一季小而完整。** 用“勇者讨魔王”作为规模骨架，不必照搬传统剧情。先做一座人类城、若干村落和外族聚居地，加一个敌对阵营，约 5–6 个地区；10 个以内可接受。按地区模拟，大型城市只需一座，优先把居民和活动做得可信，而不是扩大地图。
- **经济先跑通资源和运输。** 资源能送到城镇才有交易；货多价低、货少价高。功能建筑吸引特定路人，经过时可更新金钱、饥饿等状态。玩家切断关键运输节点后，相关地区逐渐衰落。无玩家干预时维持常态，不等于世界每一天都静止。
- **按游戏内的天结算。** 在统一时点汇总玩家当日行为和世界自身的变化，再由 AI 推演下一天，无需逐帧演算。
- **基础玩法打底，故事把世界串起来。** 从“想传达什么”出发，把叙事种子放进世界，让 AI 在已有规则内推演不同故事。推演不能越过机制边界；可信和可重复游玩比无限自由更重要。

## 当前倾向

- **战斗倾向即时制，不走回合制。** 已知代价是玩家可能直接打过去而不用道具；独立补给槽是应对手段。战前选带、制作道具能否补足这一点，仍需验证。
- **技术上倾向 2D。** 便于控制经济模拟和地形交互的复杂度；如果引入经营，生产力设定和模拟深度都要克制。
- **双世界与入侵主线。** 白天在镇上营生，夜间入睡后去另一侧战斗；先通过日常与支线建立对 NPC 的熟悉感，之后从酒馆老板等熟人出现异样开始，逐步揭示亚空间渗入现实。双世界必须有世界内的解释，而不只是剧情包装。异世界转生是可选开局，不是定案。
- **长铺垫、少数强记忆点。** 喜欢能重新解释玩家早期行为的认知反转，可加入适量 Meta 元素。参考《Undertale》对 RPG 数值语言的反转、《原神》对敌人身份的重释，以及《Scorn》对角色关系的重释；不把参考作品的具体情节当成本项目设定。

## 尚未决定

| 议题 | 讨论中的选项或问题 |
| --- | --- |
| 药水分层 | 只保留基础药，或允许基础药合成强效药。两条路线都要避免稀有药被囤到通关；合成是否只省负重、是否提高效力，未定。 |
| 剧本基调 | 偏沙盒自由，还是偏角色代入？代入能加重选择的情感分量，也可能让玩家不愿自由尝试。共同底线是避开“魔族卷土重来”式的陈套。 |
| 模拟深度 | 经济和经营算到哪一层？AI 担任 DM 时，哪些状态与规则可以变化、哪些边界必须守住？ |

## 评审时的判断标准

新增设计先问三件事：玩家会主动用吗？它能在每日推演和现有规则里自圆其说吗？它能让第一季的少数地区更有内容，还是只让地图和系统变大？
