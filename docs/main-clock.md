# 正式 Main 的时间

无档从井边村第一天 06:00 开始；不需要按 P。现实 5 秒对应 1 游戏小时，约 2 分钟一天。HUD 显示小时和分钟，室内外连续，转场黑幕与菜单暂时隐藏。太阳、月亮、环境色、池水与夜灯都采样同一时刻。账册以整小时结算，存档同时保留该小时内的秒数。关闭游戏不补算现实时间。

旧实现把画面停在 14:00 (`Almanac.halted = true`)，但会话另从 06:00 推进经济。现在 Main 只通过 Almanac 给账册传递帧时间，天空与 HUD 从账册取样；独立场景没有账册时才运行预览时钟。

室外开发时刻快捷键 1/2/3 跳到下一个相应时刻并定格；如果目标在当天已经过去，则前进至次日。跳过的小时正常结算一次，定格时重复选择同一时刻不再推进。P 恢复或暂停，运行时按住 T 加速。账册手动推进仍走同一个整点结算入口。恢复存档只重新采样，不重新结算。

回归：`godot --path . --script res://tests/main_clock_checks.gd`（需要图形窗口）。使用独立测试槽启动项目默认 Main，不发输入，比较 6 秒前后的 HUD、经济整点、日照和室外渲染像素；随后独立检查预设重复、过门、暂停期间手动推进、室内存读档及出门。
