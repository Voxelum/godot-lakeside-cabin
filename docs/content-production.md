# 城镇、村庄与幻想怪物：素材扩充讨论稿

[返回系统总览](../SYSTEMS.md)。本页是制作建议，不是功能承诺。

## 建筑：先确定用途，再生成外观

建议用「少量建筑原型 + 有约束的变体 + 手工布置关键位置」，而不是为每栋房子建独立模型，也不是随机拼所有部件。

- **首批原型：** 农舍、窄面镇屋、临街铺面、谷仓／工棚。轮廓先区分：村屋低而宽，镇屋窄而高，谷仓屋顶大，铺面有朝街的招牌和雨棚。保留现有小屋为独特地标。
- **变体规则：** 地块尺寸决定可选体型；屋顶只接匹配跨度，门必须朝向可达的小路或街面，坡地用基础或台阶接地。屋顶形状、烟囱、侧棚、窗位先变轮廓；墙材、色板、百叶和门前杂物再做区分。按地块用固定种子，允许作者锁定和覆盖；不在每次加载时重抽。建筑身份与外观变体分开，换皮不应重置存档。
- **模块约定：** 统一尺寸、原点和朝向，定义入口、台阶、招牌、壁灯挂点和碰撞。普通房屋先做外壳；需要进入的房屋单独接室内落点和现有黑场，不为每栋楼配完整内景。

## 聚落：组合街区，不是复制房子

村庄先画主路、水井或晒场，再摆朝路的农舍、菜地和后院；城镇先画主街、市场和支巷，再用窄面铺屋形成街墙，沿街保留转角、小院和通往后门的路。地标手工摆，普通地块才批量出变体。生活感优先用能说明用途的摆件：店门前有待搬货箱，工棚旁有材料，农舍边有柴堆和围栏。不必先模拟所有居民。

**首轮验收：** 用同一批模块摆一段村路和一个城镇街角。用实际斜俯视像素镜头看：关掉材质后能否分辨用途、门是否好找、前后排是否遮路、台阶能否走通、两处是否看起来像不同聚落，而不是同一组房子换色。

## 怪物：先有剪影，再有招牌动作

参考传统异世界 RPG 的熟悉印象，但不承诺照搬等级、掉落、属性克制或完整战斗机制。项目无角色等级；用栖息地、遭遇危险度和是否成群来分组。

| 候选场景 | 怪物与辨识点 |
| --- | --- |
| 村外与林地 | 史莱姆：软团、压扁回弹；哥布林：尖耳、驼背、结伴试探；狼／魔狼：低伏、绕侧、扑出；食人花：先像植物，再张口伏击。 |
| 城郊、暗渠与遗迹 | 巨鼠：长尾、贴墙窜动；骷髅兵：骨架与盾牌、咔哒步态；僵尸：拖步、迟缓但持续逼近。 |
| 荒野、洞穴与巢穴 | 兽人：厚肩、重武器、营地痕迹；巨型蜘蛛：展开的长腿和吐丝预兆；巨蜂：悬停后冲刺；小恶魔：角翼剪影和火系蓄力。 |

**首批建议：史莱姆、哥布林、狼。** 三只分别验证软体轮廓、可复用人形骨架、四足步态。每只先交一个配色、待机、移动和一个招牌动作；远镜头从剪影和动作就能认出，才开始换武器、加头盔或做狼群与陷阱。哥布林可先做持棒与持矛两种外观，同骨架、不同轮廓；外观变体不自动等于新的 AI。
